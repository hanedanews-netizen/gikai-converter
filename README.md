# 議会文書表 変換ラボ v2.11

## 今回の変更
- 丸型収受印の検出位置・検出直径・候補判定はv2.10のままです。
- **OCRで白く消す自動検出枠のみ**、ページ高さの1.8%（およそ本文1文字の高さ）だけ上へ平行移動しました。
- 除外枠の幅・高さは従来どおり検出枠の1.5倍です。
- 赤いプレビュー枠も同じ位置に移動します。
- 手動ドラッグで指定した除外範囲は変更しません。
- 本文の文字まで消えるおそれがあるため、赤枠を確認してから実行してください。
- OCRエンジン・Word出力は変更していません。OpenAI APIは使用しません。

## 更新方法
`index.html`、`style.css`、`app.js`、`stamp.js`、`README.md` をGitHub Pagesのリポジトリ直下にアップロードしてください。
