# 議会文書表 変換ラボ v2.4（非公式実験版）

GitHub Pages用の静的サイト。4ファイルをリポジトリのルートに上書きしてください。

## 更新内容
- 大田区議会の実物写真に合わせて1ページ目の独立した付託委員会枠、受理番号・受理年月日同一行、件名、提出者を配置
- 不要な「陳情文書表」の独立タイトルを削除
- 本文枠の固定高さと改ページの保守的な再調整
- 画像OCRに限り、ページ上端12%の任意除外機能（収受印対策の簡易版）。自動印影認識ではない
- Word出力ファイル名と画面上の版数をv2.4へ変更

## 注意
手書きOCRはTesseract.jsを使用しており、ChatGPTの画像認識とは性能が異なります。OCRの精度改善を保証する更新ではありません。Wordの改ページ・外枠は環境によって変わるため実機確認が必要です。PDFは利用者のブラウザで処理され、OpenAI APIは使用しません。
