# 議会文書表 変換ラボ v2.6

GitHub Pages用の静的Webアプリ。OpenAI APIキーやChatGPT契約は使用しません。

## v2.6: 収受印の四角・丸型候補検出

- 「収受印候補を探す」でPDF各ページを画像として解析し、四角形の輪郭線と円形の輪郭線から候補を表示します。
- 候補は自動で削除されません。チェックした候補のみOCR用画像を白塗りします。
- 検出漏れはプレビュー画像上をドラッグして手動で除外範囲を指定できます。
- OCR前に範囲を指定してください。対象ページでは埋め込みテキストを使わず、画像OCRを強制します。
- 印影と本文が重なる場合、本文も消えるので注意してください。
- 幾何学的な輪郭検出であり「収受」「受付」の文字意味認識ではありません。表・図形・丸数字なども候補になり得ます。検出精度は未検証です。
- 手書き日本語のOCRエンジンはTesseract.jsのままで、ChatGPT同等の認識精度にはなりません。

## 注意

PDFはブラウザ内で処理しますが、外部CDNからライブラリやOCRモデルを取得します。公開文書のみで試し、必ず原本と照合してください。収受印除外はOCR画像のみに適用され、元PDFは変更されません。
