# 議会文書表 変換ラボ v2.17

## 変更点
- 丸型収受印の**候補チェックで位置を決定**し、独立した「消去する四角い枠のサイズ」でサイズを選ぶ2段階操作に変更。
- PDFページごとに6種類のマスクを選択可能（小1.15倍、中1.35倍、標準1.50倍、横長1.85×1.35倍、大1.85倍、特大2.20倍）。
- 選択直後に**赤枠プレビューを更新**。候補の位置、検出アルゴリズムは変更しない。
- 赤枠と実際のOCR白塗りは同じ計算を使用。PDF原本は変更しない。
- 手動ドラッグで作った枠は指定どおりのサイズのまま。
- 収受印が本文と重なる場合は本文まで消えるため、枠を小さくするか手動指定すること。
- 認識精度やWordレイアウトは変更していない。ChatGPT APIへの課金なし。

JS構文検証済み。実際のブラウザでの操作とWord出力は未検証です。

## v2.17 追加：OCR・本文抽出の対象ページ
STEP 1で以下から選べます。
- すべてのページを対象（先頭から）
- 1ページ目を無視（**標準**）
- 1・2ページ目を無視（3ページ目から）

対象外ページはOCR・本文への取り込みを行いません。1ページ目の管理情報は従来どおり任意の候補取得に使う場合があります。ページ数が不足する場合はエラーを表示します。収受印の候補表示・除外枠サイズ設定、Word出力には変更ありません。

## v2.17 改善：本文の欠落・1ページ目の空白を防止
- Wordの本文表の高さを `EXACT`（厳密固定）から `ATLEAST`（最小高さ）へ変更。行が多い場合に隠れることを避けます。
- 1ページ目の本文枠を13100→10400 twipに縮小し、管理情報と本文を同一ページに配置しやすくしました。
- 続きページの本文枠は15000→13800 twipに調整しました。
- 1ページ目22行、続きページ30行を上限とする保守的な分割に変更。1行の長さは全角約46文字換算。
- Wordのファイル名に `v2_17` を明記。OCR・収受印・ページスキップの機能は従来どおり。

**注意：** Wordは端末やフォントで改ページが変わるため、固定下枠がページ下部と完全一致する保証はありません。長文で追加ページが発生する場合があります。原文との照合が必須です。
