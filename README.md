# 議会文書表 変換ラボ v2.15

## 変更点
- 丸型収受印の**候補チェックで位置を決定**し、独立した「消去する四角い枠のサイズ」でサイズを選ぶ2段階操作に変更。
- PDFページごとに6種類のマスクを選択可能（小1.15倍、中1.35倍、標準1.50倍、横長1.85×1.35倍、大1.85倍、特大2.20倍）。
- 選択直後に**赤枠プレビューを更新**。候補の位置、検出アルゴリズムは変更しない。
- 赤枠と実際のOCR白塗りは同じ計算を使用。PDF原本は変更しない。
- 手動ドラッグで作った枠は指定どおりのサイズのまま。
- 収受印が本文と重なる場合は本文まで消えるため、枠を小さくするか手動指定すること。
- 認識精度やWordレイアウトは変更していない。ChatGPT APIへの課金なし。

## 更新
ZIP内の `index.html` `style.css` `app.js` `stamp.js` `README.md` をGitHub Pagesのリポジトリ直下へ上書きアップロードしてください。

JS構文検証済み。実際のブラウザでの操作とWord出力は未検証です。
