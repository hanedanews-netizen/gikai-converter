# 議会文書表 変換ラボ v2.10

## 変更点
千代田区議会公開の送付8－3、8－7、8－9の本文ページを比較し、丸型収受印の外径をページ幅の約8.2%と想定。検出対象はページ幅比6.8～10.0%、ページ下部32%に限定しています。

- サイズ学習用の複数PDFアップロードは不要。
- 画像内の円形輪郭候補を表示し、**利用者がチェックした候補のみ**OCR用画像から除外。
- 検出できない場合はドラッグで手動除外可能。
- 印影の位置・縮尺・欠けなどにより検出できない場合があります。文字として「収受」を識別する機能ではありません。
- 収受印と本文が重なる場合、除外により本文も消える可能性があります。
- 手書きOCRの精度は改善していません。

## 公開方法
5ファイル（index.html、style.css、app.js、stamp.js、README.md）をGitHub Pagesのリポジトリ直下にアップロードしてください。

OpenAI APIは使用しません。PDFの処理はブラウザ内で行います。

## v2.10 の変更点

- 円形の収受印の検出サイズ（直径約8.2%、許容6.8〜10.0%）は変更しません。
- **選択した丸型候補**のOCR除外領域を、検出された四角形の中心から幅・高さそれぞれ1.5倍に拡大しました。
- 拡大した除外範囲をプレビューに赤枠で表示します。
- 手動ドラッグした範囲は拡大しません。本文が重なる場合は手動で指定してください。
- OCRの読み取り精度そのものは変更していません。
